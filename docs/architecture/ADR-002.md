# ADR-002: Sleeper and jitter injection

Status: Accepted

## Context

Retry backoff must be exactly 2s before try 2 and 4s before try 3 (plus 0–20% jitter), and 429 may override with `Retry-After`. Real wall-clock sleeps make AC-001 tests slow and flaky; a global `math/rand` stub couples unrelated tests.

## Decision

Backoff waiting is an injectable `sleeper` func field on `fetcher`; jitter is a separate `func() float64` field. Production uses a context-aware timer and zero (or real) jitter; tests supply deterministic stubs. Sleep runs only when another try will actually run.

## Consequences

- Tests assert exact durations and cancellation without waiting out backoff.
- No `Clock` interface or extra dependencies in `go.mod`.
- `beforeAttempt` (rate-limiter token) remains a separate per-try hook.
