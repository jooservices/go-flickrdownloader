# ADR-004: Parent-context cancellation detection

Status: Accepted

## Context

`http.Client.Timeout` cancels a child request context while the parent run context may still be valid. That case must be INCOMPLETE (preserve `.part`) per AC-003. True user cancellation (Ctrl-C) must be FATAL and excluded from per-photo failure reporting (AC-015/BR9). Matching timeout via error strings is fragile across Go releases.

## Decision

`classifyTransport` consults **only** the parent `ctx` handed to `fetcher.run`, and checks it first. A cancelled parent → FATAL wrapping `errCancelled`; a clean parent with a transport/timeout error → INCOMPLETE. All cancel paths (transport, sleeper, `beforeAttempt`) wrap `errCancelled` and are tested with `errors.Is`.

## Consequences

- Client timeouts remain resumable; Ctrl-C stops retries and skips failure counts.
- Version-stable cancellation detection without error-string matching.
