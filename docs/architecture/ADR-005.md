# ADR-005: Client timeout location

Status: Accepted

## Context

AC-003 requires the existing 60-second full-request timeout to remain unchanged in behavior. Replacing it with per-request `context.WithTimeout` would alter cancellation semantics and risk classifying timeouts as parent cancellation.

## Decision

The 60s timeout stays on `http.Client.Timeout`, applied per attempt. Ownership moves from a package-level client to a `Downloader.httpClient` field constructed in `New` and passed into each `fetcher`.

## Consequences

- Timeout behavior is preserved for AC-003 (INCOMPLETE, `.part` kept).
- Tests can inject a shorter-timeout client without changing production policy.
- Rejected: per-request `context.WithTimeout` replacing `http.Client.Timeout`.
