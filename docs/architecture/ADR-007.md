# ADR-007: allowIDAbsentSweep caller flag

Status: Accepted

## Context

`downloadPhotosFromPages` drives both per-album downloads and the orphan/owner-root batch. AC-017/AC-018 allow the ID-absent stale-artifact sweep only inside fully-listed per-album directories — never at owner-root. Inferring “album-ness” from `OutDir` shape is fragile.

## Decision

Sweep eligibility is an explicit `allowIDAbsentSweep bool` parameter. Call sites pass `true` from the photoset loop and `DownloadByPhotoset`; `false` for uncategorized/orphan downloads. `DownloadPhoto` never calls `downloadPhotosFromPages` and never sweeps.

## Consequences

- Sweep scope is obvious at each call site and covered by tests (AC-017/AC-018).
- Rejected: inferring eligibility from directory layout or other ambient state.
