# ADR-010: Single length sentinel

Status: Accepted

## Context

Expected total size is tracked in-memory per try (AC-005). `http.Response.ContentLength` already encodes absence as `-1`. Coercing “unknown” to `0` would collide with a server-declared empty body and silently skip the “unknown → skip size check” branch.

## Decision

One sentinel scheme for expected totals: `< 0` unknown (skip size-completeness), `== 0` declared-empty, `> 0` known length. Values are taken verbatim from `Content-Length` (200) or `Content-Range` complete-length (206/416); never coerced. The 206 identity gate additionally requires `total > 0`, so `*` or non-positive lengths fail and route to the AC-011 fallback rather than inventing a cap.

## Consequences

- Unknown length never falsely triggers zero-byte UNUSABLE via the size check (zero-byte is still UNUSABLE independently via AC-014).
- Gated 206 caps use a real complete-length only.
