# ADR-011: Ingest extraction

Status: Accepted

## Context

Response *handling* (HTML header check → copy → validate → promote/delete) must be shared by plain GET and Range paths. Having `rangeGet`'s 200 branch (Range ignored) call `plainGet` would re-issue the request — two `Do` calls, two round trips, and a race between responses — for a body already in hand.

## Decision

`ingest` owns everything downstream of a received response and issues **no** requests. `plainGet` = one `Do` + `ingest`. `rangeGet`'s 200 branch calls `ingest` directly on the response already received (one request). Only Gate-A 206 failures and mismatched 416 legitimately cost a second request in the same try.

## Consequences

- Range-ignored 200 is one request and one limiter token (per try).
- Candidate vs authoritative `.part` deletion rules live in one place (`isCandidate`, `preserveOnUnusable`).
- Rejected: delegating the 200 branch to `plainGet`.
