# ADR-013: Best-effort promote sibling cleanup

Status: Accepted

## Context

After a validated file is renamed to the final path, BR7 removes any sibling `.part`/`.cand`. Treating that cleanup failure as FATAL would mark a complete, correct photo as failed and trigger a re-download on the next run.

## Decision

`promote` returns nil if and only if `os.Rename` succeeded. Sibling `.part`/`.cand` removal afterward is **best-effort**: failures are logged and ignored, never converted into an error or FATAL outcome.

## Consequences

- A successful download is never reported failed because of stray-artifact cleanup.
- Leftover siblings are reclaimed by a later resume path, try-start `.cand` delete, or the end-of-album sweep.
